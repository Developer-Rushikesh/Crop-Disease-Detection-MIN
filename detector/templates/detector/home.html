Technology Stack

Built with Modern Open-Source Technologies

A clean Django full-stack application using optimized Convolutional Neural Network inference.

Backend Framework Python 3.12 & Django 5.0 (MVT)
Neural Network MobileNetV2 (PlantVillage Weights)
Inference Engine TensorFlow Lite (<50ms CPU Runtime)
Image Processing Pillow (PIL RGB Preprocessing)
Report Generation ReportLab PDF Document Engine
Frontend Interface Responsive HTML5, Vanilla CSS & JS
